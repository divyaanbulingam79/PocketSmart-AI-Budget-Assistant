# PocketSmart AI: Your Smart Budget & Recommendation Assistant

PocketSmart AI is a smart personal finance assistant that helps users track expenses, manage budgets, and get AI-powered saving recommendations.

### Problem Statement
Many students and young professionals struggle to manage monthly budgets and overspend.

### Features
- Smart Expense Categorization
- AI Budget Recommendations
- Spending Alerts & Insights
- Savings Goal Tracker
- Chat Assistant

### Tech Stack
Frontend: React.js | Backend: Python Flask | DB: MongoDB | AI: Python ML

### Project Phases
This repo contains all 8 phases from Ideation to Demonstration.
